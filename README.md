# スタイリッシュ企画書メーカー

訴求力の高い企画書を数分で作成できるWebアプリケーションです。

## 特徴

### Phase 1 機能
- **リアルタイムプレビュー**: 入力した内容が即座に反映されます
- **3つのスタイリッシュなテンプレート**:
  - モダン（紫〜青のグラデーション）
  - プロフェッショナル（落ち着いたネイビー）
  - クリエイティブ（明るいオレンジ〜ピンク）
- **レスポンシブデザイン**: PC・タブレット・スマートフォンに対応

### Phase 2 機能（NEW!）
- **📸 画像アップロード**: ロゴや画像を企画書に追加できます
- **🎨 カラーカスタマイズ**: テンプレートの色を自由に変更できます
- **📄 PDF出力**: 企画書をPDFファイルでダウンロードできます
- **💾 自動保存**: 入力内容が5秒ごとに自動保存されます
- **📂 保存・読み込み**: ブラウザに保存して後で続きから編集できます
- **初心者にも優しい**: HTML, CSS, JavaScriptのシンプルな構成

## 使い方

### 基本的な使い方
1. ブラウザで `index.html` を開く
2. 左側の入力エリアに企画書の内容を入力
3. 右側でリアルタイムにプレビューを確認
4. テンプレートボタンでデザインを切り替え

### Phase 2 機能の使い方
- **画像追加**: 「📸 ロゴ・画像をアップロード」から画像を選択
- **色変更**: 「🎨 カラーカスタマイズ」でメインカラーとアクセントカラーを変更
- **保存**: 「💾 保存する」ボタンで入力内容をブラウザに保存
- **読込**: 「📂 読み込む」ボタンで保存したデータを復元
- **PDF出力**: 「📄 PDFで出力」ボタンでPDFファイルをダウンロード
- **クリア**: 「🗑️ クリア」ボタンで全ての入力をリセット
- **自動保存**: 入力すると5秒ごとに自動的に保存されます
