# スタイリッシュ企画書メーカー

訴求力の高い企画書を数分で作成できるWebアプリケーションです。

## 特徴

- **リアルタイムプレビュー**: 入力した内容が即座に反映されます
- **3つのスタイリッシュなテンプレート**:
  - モダン（紫〜青のグラデーション）
  - プロフェッショナル（落ち着いたネイビー）
  - クリエイティブ（明るいオレンジ〜ピンク）
- **初心者にも優しい**: HTML, CSS, JavaScriptのシンプルな構成
- **レスポンシブデザイン**: PC・タブレット・スマートフォンに対応

## 使い方

1. ブラウザで `index.html` を開く
2. 左側の入力エリアに企画書の内容を入力
3. 右側でリアルタイムにプレビューを確認
4. 下部のボタンでテンプレートを切り替え

## プロジェクト構成

```
my-first-app/
├── index.html        # メインHTMLファイル
├── css/
│   └── style.css     # スタイルシート（3つのテンプレート含む）
├── js/
│   └── app.js        # JavaScript（リアルタイムプレビュー機能）
└── README.md         # このファイル
```

## 技術スタック

- HTML5
- CSS3（グラデーション、アニメーション、レスポンシブ対応）
